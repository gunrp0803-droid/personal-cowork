# 0.2.0 ChatGPT 대응 확인 범위

확인일: 2026-10-01.

## 변경한 동작

공통 스킬은 대화에 실제로 제공된 도구를 기준으로 Chat, Work Cloud, 로컬 Work, Codex의 자료 경로와 상태 저장 방식을 결정합니다. Python·쓰기 공간·실제 상태 스크립트가 있어야 상태 도구를 사용하며, 실행할 수 없으면 Markdown 또는 대화 안의 진행 기록과 인계를 사용합니다. 기본 프롬프트에서 Codex의 `$` 호출 표기를 제거했습니다.

ChatGPT에 지침 자료로 제공할 단일 Markdown과 패키지를 공통 소스에서 생성하도록 구성했습니다. 생성된 파일은 계정 등록과 설치를 자동 수행하지 않습니다.

## 형식과 패키지 확인

- 수정한 스킬은 skill-creator의 `quick_validate.py`를 통과했습니다.
- Codex CLI 0.159.1의 읽기 전용 `plugin/read`가 버전 0.2.0, 포함 스킬, 기본 프롬프트, 아이콘 경로를 정상 해석했습니다. 플러그인 설치 상태는 `false`입니다. [정규화한 네이티브 읽기 근거](v02-plugin-read.json).
- 패키지 생성 스크립트를 실제 실행하여 플러그인 ZIP, 스킬 ZIP, 단일 Markdown을 생성했습니다. 압축 항목의 원본 바이트 일치와 CRC, 경로·중복 항목, 제외 디렉터리, Markdown의 공통 지침·인라인 참고 문서를 확인했습니다. 압축 해제한 스킬의 상태 도구 `--help`도 실행했습니다.
- 패키지 스크립트는 허용하지 않는 출력 경로를 거부하고 기존 비대상 결과물을 보존했습니다. JSON과 문서의 상대 링크도 확인했습니다.

상태 도구의 코드는 변경하지 않았습니다. 기존 15개 테스트의 결과는 0.1.0 검증 기록에 있으며, 위 검사가 ChatGPT 계정의 실제 설치 검증을 대신하지 않습니다.

## 제한 환경의 행동 평가

별도 에이전트가 수정한 `SKILL.md`만 읽은 뒤, 아래 테스트 작업에는 파일·Python 도구를 사용하지 않았습니다.

| 사례 | 관찰 결과 |
|---|---|
| 파일 쓰기·Python 없는 Chat에 지출 7건 제공 | 식비 23,500원·학습 27,000원·교통 5,300원·전체 55,800원을 본문으로 집계하고 산술 대조. 파일 저장·해시 검증·영속 상태 보관을 주장하지 않음 |
| 로컬 컴퓨터 연결 없는 Work Cloud에 로컬 CSV 경로만 제공 | 파일 접근·내용·분석 완료를 주장하지 않고 입력 자료가 필요함을 설명 |

이 테스트는 지침에 대한 제한 환경 행동 평가입니다. 실제 ChatGPT Chat 또는 Work 계정에서 플러그인을 설치·발견·실행한 증거는 아닙니다.

## 공식 지원과 실제 설치의 구분

- 공식 문서는 설치된 플러그인을 일반 Chat과 Work에서 사용할 수 있다고 안내합니다. [플러그인 지원 환경](https://learn.chatgpt.com/docs/plugins).
- Plugin Creator 생성 경로는 계정·워크스페이스에 기능과 사용 권한이 있어야 합니다. [생성 안내](https://learn.chatgpt.com/docs/build-plugins).
- 직접 스킬 생성·업로드의 공식 대상은 적격 Business·Enterprise·Healthcare·Edu 계정이며 설정과 제공 여부에 영향을 받습니다. 구체적 파일 확장자는 해당 안내에 명시되어 있지 않습니다. [스킬 안내](https://help.openai.com/en/articles/20001066-skills-in-chatgpt).

ChatGPT 계정의 실제 등록·설치·자동 활성화·두 모드의 실행 결과는 아직 확인하지 않았습니다. 기존 `verification/*.json`의 0.1.0 결과는 당시 Codex 탐색과 로컬 실행의 기록입니다.
