# 개인 계정 자동 갱신 검증

검증일: 2026-10-01. 이 문서는 해당 시점의 확인 범위를 기록합니다. 계정 식별자와 로컬 개인 경로는 공개 저장소에 기록하지 않습니다.

## 준비 단계

- 기존 개인 계정 플러그인이 `USER` 범위와 `PRIVATE` 공개 범위를 유지하며 버전 0.1.0으로 저장되어 있음을 Plugin Creator 소스 조회로 확인했습니다.
- 현재 계정 파일은 루트 manifest, 기존 Codex manifest, Personal Cowork 스킬입니다. 기존 기본 프롬프트는 문자열 배열이며 전체 값과 순서를 보존하도록 갱신 도구를 구성합니다.
- 개인 계정용 직접 GitHub 연결은 현재 공식 문서와 사용 가능한 도구에서 확인하지 못했습니다. 같은 로컬 대화의 예약 작업과 계정 갱신 API를 조합합니다.

## 확인한 결과

| 항목 | 결과와 범위 |
|---|---|
| 로컬 테스트 | 계정 갱신 준비 17개, 소스 경계 5개, 기존 상태 도구 15개, 총 37개 통과 |
| GitHub 소스 고정 | 공개 저장소 `main`의 `f5ae4e3966815bc8cbf5b03b72cf8f24ff83ad0c`에서 root manifest와 스킬 파일 4개를 별도 snapshot에 가져옴 |
| 계정 저장 | Plugin Creator가 기존 개인 플러그인을 0.1.0에서 0.3.0으로 `updated` 처리, 기존 ID와 `USER`/`PRIVATE` 유지 |
| 계정 소스 재조회 | root manifest와 스킬 파일 4개가 준비한 ZIP과 바이트 단위로 같음 |
| 기존 호환 manifest | backend가 root와 같은 `repository`를 기존 Codex manifest에 추가함. 추가 필드와 버전을 제외한 원래 메타데이터·기본 프롬프트 전체 값, 타입, 순서가 같음을 확인 |
| 검증 상태 저장 | 재조회한 실제 파일 지문과 확인된 릴리스만 원자적으로 기록 |
| 반복 실행 | 실제 계정 재조회 자료와 같은 GitHub 소스로 `noop`, ZIP 없음, 추가 게시 없음 |
| 예약 등록 | 같은 로컬 대화의 매시간 heartbeat를 생성했고 `ACTIVE` 확인 |
| 다음 예약 실행 | 아직 관찰하지 않음. 아래 기록은 수동으로 한 번 수행한 실제 동기화와 예약 등록의 증거이며 미래 실행 성공을 뜻하지 않음 |

원격 소스의 Python·셸 코드는 실행하지 않았습니다. 검토한 로컬 도구만 실행합니다. 계정 ID, 릴리스 ID, 예약 설정, 개인 경로와 runtime 상태는 공개 GitHub에 포함하지 않습니다. 별도로 업로드한 독립 스킬은 갱신하지 않았으며 현재 계정 플러그인에 포함된 스킬을 반영했습니다.

후속 수정에서 정상 `token-efficiency.md`·`tokenizer.py` 파일이 민감 토큰 파일 이름과 구분되어 포함되는 회귀 검증을 추가했고, root/기존 Codex manifest의 누락된 `repository`를 갱신 준비 단계부터 맞추도록 보완했습니다.

## 범위

개인 계정 소스의 저장 성공은 일반 Chat·Work에서 실제 작업을 수행한 증거가 아닙니다. 예약 등록은 앞으로의 모든 실행 성공, Mac 수면 중의 실행, 즉시 웹훅 배포, 다른 계정·독립 스킬의 갱신을 보장하지 않습니다.
