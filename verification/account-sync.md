# 개인 계정 자동 갱신 검증

검증일: 2026-10-01. 이 문서는 해당 시점의 확인 범위를 기록합니다. 계정 식별자와 로컬 개인 경로는 공개 저장소에 기록하지 않습니다.

## 준비 단계

- 기존 개인 계정 플러그인이 `USER` 범위와 `PRIVATE` 공개 범위를 유지하며 버전 0.1.0으로 저장되어 있음을 Plugin Creator 소스 조회로 확인했습니다.
- 현재 계정 파일은 루트 manifest, 기존 Codex manifest, Personal Cowork 스킬입니다. 기존 기본 프롬프트는 문자열 배열이며 전체 값과 순서를 보존하도록 갱신 도구를 구성합니다.
- 개인 계정용 직접 GitHub 연결은 현재 공식 문서와 사용 가능한 도구에서 확인하지 못했습니다. 같은 로컬 대화의 예약 작업과 계정 갱신 API를 조합합니다.

## 검증 진행 상태

갱신 준비 도구의 테스트, GitHub 소스에서 계정 갱신 및 재조회, 반복 실행 시 재게시 방지, 매시간 예약의 생성 결과는 완료 후 이 기록에 추가합니다. 현재 이 준비 단계만으로 계정 갱신이나 자동화 실행 성공을 주장하지 않습니다.

## 범위

개인 계정 소스의 저장 성공은 일반 Chat·Work에서 실제 작업을 수행한 증거가 아닙니다. 예약 등록은 앞으로의 모든 실행 성공, Mac 수면 중의 실행, 즉시 웹훅 배포, 다른 계정·독립 스킬의 갱신을 보장하지 않습니다.
