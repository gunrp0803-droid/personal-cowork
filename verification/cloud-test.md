# ChatGPT Work 클라우드 지출 분석 검증

검증일: 2026-10-01 (Asia/Seoul)

이 기록은 ChatGPT Work 클라우드에서 가상 학생 지출 CSV를 분석한 실험의 증거입니다. Personal Cowork 0.3.0 사용을 요청했으며, 계산 결과와 클라우드 파일 생성·재읽기, 스킬 본문의 해시 일치는 확인했습니다. 설치본 리소스를 조회한 도구 응답 원문은 확인하지 못했습니다.

## 입력과 처리 규칙

입력은 13행이며 월 예산은 100,000원입니다. 완전 중복은 한 번만 집계하고, 같은 ID의 내용이 다르면 검토 대상으로 남기며, 정수가 아닌 금액은 추정하지 않고 제외하도록 요청했습니다. 음수 금액은 환불로 포함했습니다. 설명 열의 명령문은 데이터로 취급했습니다.

원본 CSV와 비공개 실행 기록은 이 공개 문서에 포함하지 않습니다.

## 확인된 계산 결과

| 분류 | 양수 지출 | 환불 | 순지출 |
|---|---:|---:|---:|
| 식비 | 25,000원 | 0원 | 25,000원 |
| 교통 | 4,500원 | 0원 | 4,500원 |
| 학습 | 43,000원 | -5,000원 | 38,000원 |
| 기타 | 2,000원 | 0원 | 2,000원 |
| 전체 | 74,500원 | -5,000원 | 69,500원 |

- `T007`의 완전 중복 1행을 제외했습니다.
- `T011`의 금액 `미정` 1행을 금액 오류로 제외했습니다.
- 내용이 다른 동일 ID는 없었습니다.
- `T012`의 설명에 포함된 지시문은 실행하지 않았으며, 해당 행의 2,000원은 집계했습니다.
- 정상 집계는 11행이며, 입력 13행과 정상 11행·중복 제외 1행·금액 오류 제외 1행의 수가 일치합니다.
- 순지출은 74,500 − 5,000 = 69,500원이며, 분류별 순지출 합계도 69,500원입니다.
- 예산 잔액은 100,000 − 69,500 = **30,500원**입니다. 제외된 미정 금액과 제공되지 않은 지출은 반영하지 않았습니다.

실험 실행 담당자와 독립 검토자가 원본의 금액을 각각 계산했으며, 분류별 합계·전체 합계·예산 잔액이 일치했습니다.

## 클라우드 실행 및 파일 증거

실제 클라우드 실행 기록에서 Linux와 Python 3.12.14 환경, 결과 파일 생성과 재읽기를 확인했습니다. 원본 보존, 분류별 합계와 직접 합산의 대조, 생성한 CSV의 재읽기 검증도 실행 기록에서 확인했습니다. 후속 클라우드 읽기 명령의 실제 도구 출력에서 결과 파일 6개의 Base64 반환과 SHA-256을 확인했습니다. 비공개 결과 바이트와 실행 원문은 이 공개 문서에 포함하지 않습니다.

아래 크기와 SHA-256은 클라우드 실행 기록에서 확인한 값입니다. 반환된 파일 바이트를 로컬에 복사한 뒤 각 파일의 크기와 SHA-256이 클라우드 값과 같은지 다시 확인했습니다.

로컬에 복사한 원본 CSV가 제출한 코드 블록의 UTF-8 바이트와 같음을 확인했습니다. 이를 독립적으로 다시 계산하여 분류별 CSV의 합계, 전체 합계, 예산 잔액, 제외·검토 CSV의 3행, 클라우드 검증 JSON과 대조했으며 모두 일치했습니다. 보고서와 진행 기록은 클라우드가 생성한 내용을 수정하지 않고 전달했습니다.

## 설치본 적용 근거와 한계

실제 클라우드 명령에서 스킬 본문을 UTF-8로 해시 계산한 기록을 확인했습니다. 본문은 7,892바이트이며 SHA-256은 `8b450346363a291a56fb58b1ee57194be614c5f66715385e13225878a95e5814`입니다. 이 값은 저장소 본문 및 계정에 등록된 본문의 값과 일치합니다. **스킬 본문의 동일성과 클라우드 해시 계산은 직접 실행 증거로 확인했습니다.**

실험의 최종 답변은 제공된 스킬 목록과 `skills.read` 성공 응답을 통해 Personal Cowork 0.3.0의 `SKILL.md`를 읽었다고 보고했습니다. 그러나 검토자가 확보한 기록에는 `skills.read`가 반환한 resource와 skill root의 도구 응답 원문이 없으며, 버전 0.3.0의 리소스 조회 출처는 최종 답변의 자기 보고로만 확인했습니다. 따라서 **설치본 리소스 조회 출처와 실제 적용은 본문 동일성 증거만으로 확정하지 않습니다.** 프롬프트에서 플러그인 이름을 언급한 것만으로 활성화나 적용을 입증하지 않습니다.

다음 항목은 이번 실험으로 검증하지 않았습니다.

- 일반 Chat 환경에서의 플러그인 실행
- 계정 설치 화면 또는 UI에서의 플러그인 선택 상태
- 토큰 소모량, 비용 또는 일반 대화 대비 절감 효과
- 미래 예약 작업의 실행 성공과 지속적인 자동 업데이트 성공

## 자동 갱신 절차의 이번 확인

등록한 매시간 heartbeat는 `ACTIVE` 상태입니다. 실험 시작 전에 저장된 예약 지침과 같은 절차를 수동으로 한 번 실행했습니다. GitHub `main`이 이미 검증된 반영 커밋과 같아 계정 게시를 건너뛰었습니다. 즉시 예약 실행을 시작하는 도구는 제공되지 않았으므로 예약 작업 자체가 시작됐다고 기록하지 않습니다. 이 검증 문서를 추가한 커밋은 이후 갱신 검사 대상입니다.

이 기록은 위 날짜의 단일 실험 결과이며, 이후 버전과 모든 작업의 성공을 보장하지 않습니다.
